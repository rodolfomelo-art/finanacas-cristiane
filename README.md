# Landing page — Cristiane Cirrilo

Landing page responsiva para captação de clientes de mentoria e educação financeira.

## Executar

```powershell
python server.py
```

Acesse `http://127.0.0.1:8000`.

## Personalização antes de publicar

- Substitua o bloco de retrato pela fotografia oficial de Cristiane.
- Atualize e-mail, Instagram e WhatsApp no rodapé.
- Conecte o formulário em `script.js` ao CRM, WhatsApp ou serviço de e-mail desejado.
- Para produção, recomenda-se instalar Tailwind localmente em vez de usar o CDN.
